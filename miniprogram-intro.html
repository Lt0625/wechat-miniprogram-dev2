🟢 桔子记账小程序

微信原生开发 · 纯本地存储 · 零后端依赖 · 4个大版本迭代 · 74个自动化测试用例
项目概览
桔子记账是一款基于微信原生开发的个人记账工具，从 V1.0 到 V4.0 经过 4 个大版本迭代。采用纯本地存储方案（wx.setStorageSync），无需后端服务器，零运维成本，用户数据完全保存在本地，保障隐私安全。
技术架构上，通过 Component + Behavior 实现组件化复用，CSS 变量驱动主题换肤系统，Behavior 混入模式抽取主题切换、加载状态等公共逻辑。特色功能包括语音记账（识别率 95%+）、周期账单与到期提醒、预算管控与快捷记账。配套 74 个自动化测试用例（miniprogram-automator），100% 通过率，11 个模块全覆盖。
技术栈
WXML / WXSS / JavaScript Component + Behavior 微信云开发 wx.setStorageSync 本地存储 CSS 变量主题换肤 wx.translateVoice 语音识别 miniprogram-automator 测试
技术选型理由
选型理由
微信原生 vs uni-app 纯微信生态，无需跨端适配，性能最优；Component+Behavior 原生组件化足够灵活
本地存储 vs 云数据库 零后端成本，零运维，数据隐私保障；10MB 存储上限对记账场景完全够用
wx.translateVoice vs 第三方ASR 免费调用，无需注册第三方服务，微信原生API稳定性高；配合本地NLP解析实现零成本语音记账
CSS变量 vs CSS预处理器 小程序不支持Sass/Less编译，CSS变量是原生方案，运行时切换主题无需重新编译

语音记账 · 核心亮点
语音记账是本项目最具技术深度的功能。用户长按录音按钮说话，松手后微信自动将语音转为文字，然后本地 NLP 解析提取金额、分类和备注，实现3秒完成记账的极致体验。识别率从初始 40% 提升至 95%+，零后端成本。

录音格式踩坑（面试高频）
问题：微信小程序的 format 参数不可靠。文档标注输出 opus，但实际录音文件的二进制头部是 OggS（OGG 封装 Opus 编码），即真实格式是 ogg-opus 而非 opus。

根因：微信小程序的录音 format 参数只是个"建议"，实际格式由客户端决定，不能信任。

解决方案：检测文件头魔数（前4字节 0x4F676753 = "OggS"）判断真实格式，而非信任扩展名或 format 参数。识别到 ogg-opus 后，传给 wx.translateVoice 时指定 format: 'ogg-opus'。

效果：识别率从 40% → 95%+，提升超过一倍。

核心工具函数（bill-helper.js）
函数功能
calculateBalance()根据账户关联的收支账单计算余额：Σ收入 - Σ支出
updateAccountBalance()账单增删改时触发余额重算，编辑时先还原旧账单再应用新数据
checkDuplicate()检测同金额+同分类+同日期的重复账单，防止误记
calculateNextDue()根据周期类型和参数，推算周期账单的下次到期日
syncCategoryName()分类改名时遍历全部账单，批量替换旧分类名

技术亮点
🎙️ 语音记账 核心亮点
微信本地录音 → wx.translateVoice 语音转文字 → 本地NLP解析金额/分类/备注。识别率从 40% → 95%+，零后端ASR成本。
踩坑：录音 format 参数不可靠，文档写 opus 实际是 ogg-opus。检测文件头魔数判断真实格式后，识别率飙升。支持双向备注提取，自动过滤语气词。
💰 账户余额自动计算 架构设计
账单增删改时自动同步账户余额，无需手动维护。基于 bill-helper.js 集中管理计算逻辑，保证数据一致性。
机制：每笔账单关联账户，保存/编辑/删除时触发重算：余额 = Σ收入 - Σ支出。编辑时先还原旧账单影响，再应用新数据；删除时还原全额。同步按钮允许用户手动对账。
🎨 CSS变量主题系统 设计模式
全局CSS变量驱动换肤，data-theme 属性激活变量集，广播通知所有页面刷新。5种预设主题一键切换，无需重启。
踩坑：7个页面WXML根元素缺少 data-theme="" 导致CSS变量无法激活——选择器 [data-theme="orange"] 匹配不到没有该属性的元素。修复：补齐属性 + onShow 中 setData({theme}) 刷新。
🧪 全链路自动化测试 工程能力
基于 miniprogram-automator 编写74个测试用例，覆盖11个模块，100%通过率，38张截图存证。
踩坑：① WebSocket端口≠HTTP端口，需 cli.bat auto --auto-port 9420；② TabBar页面必须用 switchTab 而非 navigateTo；③ 导航路径必须加前导 /；④ action名称大小写敏感。
🔄 Component + Behavior 复用 架构设计
抽取公共逻辑为 Behavior 混入（主题切换 themeBehavior、加载状态 loadingBehavior），组件通过 behaviors: [themeBehavior] 继承能力，避免重复代码。
组件体系：全局注册组件——骨架屏（skeleton）4种类型+流光动画、全局Loading（global-loading）+脉冲动画、分类图标组件（category-icon）统一管理 emoji 映射。
🔄 周期账单 + 到期提醒 架构设计
支持4种周期（每天/每周/每月/每年），可配置具体日期，calculateNextDue() 自动推算到期日，启动时检测到期弹窗提醒。
提醒机制：app.js → checkDueRecurringBills() 小程序启动时检测今日到期账单，弹窗提示用户去记账。可配置提醒时间，支持开启/关闭单条。
📝 分类改名自动同步 数据一致性
用户修改分类名称时，自动遍历所有历史账单，将旧分类名替换为新名称，保证数据查询一致性。
设计考量：分类名作为查询key存在于账单中，改名不同步会导致统计页按旧名查询为空。系统默认分类受保护不可删除。
