桔子记账小程序
🟢

微信原生小程序 · V4.0

纯本地存储 · 零后端依赖 · 5大核心页面
一款基于微信原生开发的个人记账工具，从 V1.0 到 V4.0 经过 4 个大版本迭代。采用纯本地存储方案（wx.setStorageSync），无需后端服务器，零运维成本。通过 Component + Behavior 实现组件化复用，CSS 变量驱动主题系统，支持语音记账、周期账单、预算管控等特色功能，并配套 74 个自动化测试用例保障质量。
WXML / WXSS / JS Component + Behavior 微信云开发 CSS 变量换肤 语音记账 miniprogram-automator

填充金额/分类/备注
识别流程：用户长按录音按钮松手后，微信自动将语音转为文字，然后本地解析提取金额、分类和备注。支持双向提取——优先从金额后面取备注，金额前面没有有效备注时反向提取。自动过滤语气词（"钱"、"了"、"花了"、"用"等）。
示例："吃饭花了50块" → 金额50 + 分类餐饮 + 备注吃饭 ｜ "打车25块去公司" → 金额25 + 分类交通 + 备注去公司

Flutter 记账 APP
🔵

Flutter 跨平台 · Android & iOS

Dart语言 · Hive本地存储 · Provider状态管理
基于Flutter框架开发的跨平台记账APP，同一套 Dart 代码编译到 Android 和 iOS 两个平台。采用 Provider + ChangeNotifier 进行状态管理，Hive 作为轻量级本地 NoSQL 数据库实现纯本地持久化，GoRouter 管理声明式路由。与小程序版功能对齐的同时，利用 Flutter 特性实现 Material 3 动态主题和响应式布局。
Dart Flutter 3.x Provider Hive GoRouter Material 3 Android + iOS
架构分层
UI 层 (Widget)
→
逻辑层 (ChangeNotifier)
→
数据层 (Hive Box)
Provider 状态管理：UI 层通过 context.watch<T>() 监听数据变化自动重建，通过 context.read<T>() 获取方法触发业务逻辑，数据变更后调用 notifyListeners() 通知所有监听者刷新。这种模式将 UI 和业务逻辑完全解耦。

技术亮点
🎙️ 语音记账 核心亮点
微信本地录音 → wx.translateVoice 语音转文字 → 本地NLP解析金额/分类/备注。识别率从初始 40% 提升至 95%+，无需后端 ASR 服务，零成本方案。
踩坑详解：微信录音 format 参数不可靠，文档标注输出 opus，实际文件头为 OggS（OGG封装Opus）。解决方案：检测文件头魔数判断真实格式，而非信任扩展名或 format 参数。识别到 ogg-opus 后，传给 wx.translateVoice 时指定 format: 'ogg-opus'，识别率从 40% 飙升至 95%+。
💰 账户余额自动计算 架构设计
账单增删改时自动同步账户余额，无需手动维护。基于 bill-helper.js 工具函数集中管理计算逻辑，保证数据一致性。
实现机制：每笔账单关联账户，保存/编辑/删除时触发重算：余额 = Σ收入 - Σ支出。关键点：编辑时先还原旧账单影响，再应用新数据；删除时还原全额。同步按钮允许用户手动触发对账。
🎨 CSS变量主题系统 设计模式
全局CSS变量驱动换肤，data-theme 属性激活变量集，广播通知所有页面刷新。5种预设主题一键切换，无需重启。
踩坑详解：页面WXML根元素缺少 data-theme="" 导致CSS变量无法激活——CSS选择器 [data-theme="orange"] 匹配不到没有该属性的元素。修复：为7个页面的根容器统一补齐 data-theme=""，并在 onShow 中 setData({theme}) 刷新。
🧪 全链路自动化测试 工程能力
基于 miniprogram-automator 编写74个测试用例，覆盖11个模块（首页/日历/统计/资产/添加账单/分类管理/快捷记账等），100%通过率，38张截图存证。
踩坑详解：① WebSocket自动化端口 ≠ HTTP端口，需 cli.bat auto --auto-port 9420；② TabBar页面必须用 switchTab 而非 navigateTo，否则路径叠加报错；③ 导航路径必须加前导 /；④ format 参数大小写敏感，驼峰或错误名会静默跳过。
🔄 Component + Behavior 复用 架构设计
抽取公共逻辑为 Behavior 混入（主题切换 themeBehavior、加载状态 loadingBehavior），组件通过 behaviors: [themeBehavior] 继承能力，避免重复代码。
组件体系：全局组件注册在 app.json——骨架屏（skeleton）4种类型+流光动画、全局Loading弹窗（global-loading）+脉冲动画、分类图标组件（category-icon）统一管理 emoji 映射。
📱 Flutter跨平台编译 跨端能力
一套Dart代码同时编译Android APK和iOS IPA，Provider管理状态，Hive本地持久化，GoRouter声明式路由。代码复用率 > 90%。
跨平台差异处理：平台特定代码通过 Platform.isAndroid/iOS 条件分支处理；小米真机ADB调试（adb devices + flutter run），禁用模拟器确保手势/性能/键盘等真实体验。
🔄 周期账单 + 到期提醒 架构设计
支持4种周期（每天/每周/每月/每年），每周可选星期几，每月可选日期，每年可选月日。calculateNextDue() 自动计算下次到期日。
提醒机制：小程序启动时 checkDueRecurringBills() 检测今日到期账单，弹窗提示用户去记账。可配置提醒时间（如 09:00），支持开启/关闭单条周期账单。
📝 分类改名自动同步 数据一致性
用户修改分类名称时，自动遍历所有历史账单，将旧分类名替换为新名称，保证数据查询一致性。
设计考量：分类名称作为查询 key 存在于账单中，改名不同步会导致统计页按旧名查询为空。系统默认分类（餐饮/交通等11+10个）受保护，不允许用户删除。
