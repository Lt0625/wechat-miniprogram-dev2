技术亮点
🎙️ 语音记账 核心亮点
微信本地录音 → wx.translateVoice 语音转文字 → 本地NLP解析金额/分类/备注。识别率从40%提升至95%+。
踩坑：微信录音format参数不可靠，实际输出OGG封装Opus，必须检测文件头 OggS 判断格式，而非信任扩展名。
💰 账户余额自动计算 架构设计
账单增删改时自动同步账户余额，无需手动维护。基于 bill-helper.js 工具函数，保证数据一致性。
核心：每笔账单关联账户，保存时重新计算 = Σ收入 - Σ支出，编辑/删除时触发重算。
🎨 CSS变量主题系统 设计模式
全局CSS变量驱动换肤，data-theme 属性激活变量集，广播通知所有页面刷新。5种预设主题一键切换。
踩坑：页面WXML根元素缺 data-theme="" 导致变量不激活，需为7个页面统一补齐。
🧪 全链路自动化测试 工程能力
基于 miniprogram-automator 编写74个测试用例，覆盖11个模块，100%通过率，38张截图存证。
踩坑：WebSocket端口≠HTTP端口；TabBar页面必须用 switchTab 而非 navigateTo；导航路径必须加前导 /。
🔄 Component + Behavior 复用 架构设计
抽取公共逻辑为 Behavior（如主题切换、加载状态），通过 behaviors: [themeBehavior] 混入组件，避免代码重复。
全局组件注册在 app.json，骨架屏/Loading弹窗/分类图标等跨页面复用。
📱 Flutter跨平台编译 跨端能力
一套Dart代码同时编译Android APK和iOS IPA，Provider管理状态，Hive本地持久化，GoRouter声明式路由。
小米真机ADB调试，禁用模拟器，确保手势/性能/键盘等真实体验。
